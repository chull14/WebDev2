# Directions for Lab2

# Requirements
- node.js
- redis

# Setup
- install dependencies with:

```bash
npm install 
```

- .env in .gitignore 
- key is 546 key  
- redis server: redis://localhost:6379 

# Startup
- start redis server in separate terminal with:

```bash
redis-server 
```

- start server with 

```bash 
npm start 
```
